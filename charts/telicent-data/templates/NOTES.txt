💡 TROUBLESHOOTING:
====================
Common issues and solutions:

1. Job stuck in pending state:
   - Check resource constraints: kubectl describe nodes
   - Verify image pull secrets and registry access

2. Job failing repeatedly:
   - Check logs: kubectl logs -l app.kubernetes.io/producer=<name>
   - Verify environment variables and configuration
   - Check connectivity to data sources and Kafka

3. Data not appearing in Core:
   - Verify Kafka connectivity and topic configuration
   - Check Core application logs for processing errors
   - Validate data format and schema compatibility
