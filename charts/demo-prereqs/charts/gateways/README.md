# Demo Prerequisite - Gateways

A simple Helm chart for demo and development purposes.

## Overview

This chart provisions Istio Gateways and Authentication Policies for Telicent CORE applications and an authentication provider running in an instance of the Telicent demo cluster.

> **Note:** This chart is not intended for production use.

## Parameters

### Gateways Configuration

| Name      | Description                                            | Value  |
| --------- | ------------------------------------------------------ | ------ |
| `enabled` | Whether the Gateways prerequisite should be installed. | `true` |
