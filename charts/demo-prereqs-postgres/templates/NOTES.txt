To get the password:

  kubectl get secret --namespace {{ .Release.Namespace }} {{ include "demo-prereqs-postgres.fullname" . }} -o jsonpath="{.data.postgres-password}" | base64 -d

To connect using port-forward:

  kubectl port-forward --namespace {{ .Release.Namespace }} svc/{{ include "demo-prereqs-postgres.fullname" . }} 5432:{{ .Values.service.port }}

  Then connect using:
  psql -h 127.0.0.1 -U {{ .Values.postgres.user }} -d {{ .Values.postgres.database }}
